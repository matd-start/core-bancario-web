# Core Bancario — Web

Aplicación web (SPA) de [Core Bancario](https://github.com/matd-start/core-bancario): la banca del cliente y el backoffice del operador.

La spec, el plan y las decisiones de arquitectura viven en el repositorio `core-bancario` ([ADR-0005](https://github.com/matd-start/core-bancario/blob/main/docs/adr/0005-repositorios-separados-backend-y-frontend.md)). Este repositorio contiene el código del frontend y la bitácora de su construcción.
